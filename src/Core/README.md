# open-colibri/starter-core

Core of Colibri Starter: the Castor plugin. It provides the `SyliusService` Docker service, the `castor docker:service:install sylius` installer, the `sylius:fixtures` task and the extension points (task providers, installer/remover contracts, installer extensions) used by the other packages.

## Installation

In your Castor project:

```bash
castor composer require open-colibri/starter-core
```

Or install every Colibri Starter package at once with `open-colibri/starter`.

Read the [documentation](https://github.com/open-colibri/colibri-starter/blob/main/docs/getting-started/installation.md) for usage.
