# sylius-starter/upsun

Castor tasks to set up, check and deploy the Upsun configuration of a Sylius application:
`sylius:upsun:setup`, `sylius:upsun:check` and `sylius:upsun:deploy`.

## Installation

In your Castor project:

```bash
castor composer require sylius-starter/upsun
```

Or install every Sylius Starter package at once with `sylius-starter/sylius-starter`.

Read the [documentation](https://github.com/the-swan-foundation/the-swan-starter/blob/main/docs/commands/upsun.md) for usage.
