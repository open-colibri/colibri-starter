# opencolibri/starter-menu

Castor task to remove (and restore) Sylius admin menu items: `sylius:menu:remove`.

## Installation

In your Castor project:

```bash
castor composer require opencolibri/starter-menu
```

Or install every Colibri Starter package at once with `opencolibri/starter`.

Read the [documentation](https://github.com/opencolibri/colibri-starter/blob/main/docs/commands/admin-menu.md) for usage.
