# opencolibri/starter-upsun

Castor tasks to set up, check and deploy the Upsun configuration of a Sylius application:
`sylius:upsun:setup`, `sylius:upsun:check` and `sylius:upsun:deploy`.

## Installation

In your Castor project:

```bash
castor composer require opencolibri/starter-upsun
```

Or install every Colibri Starter package at once with `opencolibri/starter`.

Read the [documentation](https://github.com/opencolibri/colibri-starter/blob/main/docs/commands/upsun.md) for usage.
