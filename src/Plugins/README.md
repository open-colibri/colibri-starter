# sylius-starter/plugins

Castor tasks to add and remove Sylius plugins: `sylius:plugin:add` / `sylius:plugin:remove` (aliases `sylius:add` / `sylius:remove`). Custom plugins can be declared with the `#[AsPluginInstaller]` and `#[AsPluginRemover]` attributes.

## Installation

In your Castor project:

```bash
castor composer require sylius-starter/plugins
```

Or install every Sylius Starter package at once with `sylius-starter/sylius-starter`.

Read the [documentation](https://github.com/the-swan-foundation/the-swan-starter/blob/main/docs/commands/plugins.md) for usage.
