# opencolibri/starter-plugins

Castor tasks to add and remove Sylius plugins: `sylius:plugin:add` / `sylius:plugin:remove` (aliases `sylius:add` / `sylius:remove`). Custom plugins can be declared with the `#[AsPluginInstaller]` and `#[AsPluginRemover]` attributes.

## Installation

In your Castor project:

```bash
castor composer require opencolibri/starter-plugins
```

Or install every Colibri Starter package at once with `opencolibri/starter`.

Read the [documentation](https://github.com/opencolibri/colibri-starter/blob/main/docs/commands/plugins.md) for usage.
